# Anatomical HITL extension

These packages were developed after the core EvalOral manuscript analyses to explore a richer human-in-the-loop pathway toward anatomical semantics such as arch, side, and anterior/posterior organization.

- `packages/Anatomical_HITL_ReviewerKit.zip`: reviewer-facing package.
- `packages/Anatomical_HITL_AdminKit.zip`: author/admin analysis package.

They are included as a reproducible research extension, **not as evidence supporting the present paper's reported results**.
